# AEGIS v0.4 — Knowledge RAG (retrieve with citations)

**Status:** Complete through Step 3.7  
**As of:** 2026-09-10

v0.4 is the **knowledge** retrieve surface: allowlisted markdown in OpenSearch, hybrid search, citations. It is **not** investigation, not Claude, and not a dump of live Postgres incidents.

## What shipped

- **Corpus (3.0):** 24 allowlisted files — 6 runbooks, 6 closed RCAs (`docs/knowledge/incidents/INC-2026-*.md`), catalog, ADRs, architecture.
- **OpenSearch** `aegis-knowledge`: BM25 `text` + 1024-d `knn_vector` (FR-043).
- **Ingest / reindex:** `uv run python -m aegis.rag.ingest` and `--files path` (FR-045). Unchanged files can be skipped via `.aegis/rag-ingest-manifest.json`.
- **Retrieve:** `POST /api/v1/retrieve` (JWT, not HMAC) with filters and citations `{ document, section, chunk_id }` (FR-042, FR-044).
- **FR-041 gate (3.7):** the six **written** RCAs are retrievable as `doc_type=incident_report`. Live webhook rows are not in the index.

Eval labels: `evaluation/datasets/rag/queries.jsonl` (recall@8). That is RAG eval, not FR-090 RCA scoring.

## What is indexed

Only the allowlist under `docs/knowledge/`, `docs/adr/`, `docs/architecture/`, plus a few platform docs. Children chunks only.

## What is not indexed

- Live `open` incidents in Postgres
- Simulator `/signals` ticks or logs
- `src/`, `.env`, `docs/implementation-guide.md`, `queries.jsonl`
- GitHub / application source as a code index

## What did not ship (out of v0.4)

- Agents / LangGraph calling retrieve
- Claude / Bedrock generation
- EventBridge / SQS / `incident.opened.v1`
- Cross-encoder reranker
- Golden RCA **scorer** (FR-090, RISK-007 stays Partial)

Do not put secrets in this note.

## Operator

```bash
AEGIS_EMBEDDER=fake AEGIS_OPENSEARCH_URL=http://127.0.0.1:9200 \
  uv run python -m aegis.rag.ingest
# OpenAPI: POST /api/v1/retrieve on http://127.0.0.1:8000/docs
```
