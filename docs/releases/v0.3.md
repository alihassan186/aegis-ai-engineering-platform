# AEGIS v0.3 — Production simulator

**Status:** Complete (quality gate 2.7)  
**As of:** 2026-09-03

v0.3 is the fake production estate plus ingest into AEGIS as the system of record. It is complete enough to feed later RAG and agent work. It is **not** investigation yet.

FR map: [v0.3-fr-traceability.md](v0.3-fr-traceability.md).

## What shipped

- **Simulator** (`apps/simulator/`, `:8001`): five in-process services (`user`, `order`, `payment`, `inventory`, `notification`).
- **Signals:** synthetic logs, metrics, and traces (in-memory), not Datadog or OpenTelemetry collectors.
- **Six named scenarios** (config/bias, not real faults): `db_exhaustion`, `memory_leak`, `latency_spike`, `bad_deployment`, `queue_backlog`, `dependency_failure`.
- **HMAC webhook ingest:** simulator `POST /emit` → AEGIS `POST /api/v1/webhooks/incidents` with `X-Aegis-Signature` (not JWT).
- **Open-incident fingerprint (FR-007):** same service + scenario + UTC hour collapses to one **open** incident (HTTP 201 then 200).
- Operator demo: `scripts/demo-v0.3.sh`.

## What did not ship (out of v0.3)

- RAG / OpenSearch / embeddings
- Agents / LangGraph / Bedrock investigation
- EventBridge / SQS / `incident.opened.v1`
- Related-incident graph (FR-008)
- Webhook IP allowlisting (THR-002 remainder)

Do not put secrets in this note. Local HMAC and JWT values stay in `.env`.
