# AEGIS v0.6 — Tool-use guardrail (gateway, MCP, audit)

**Status:** Complete through Step 5.11
**As of:** 2026-10-07

v0.6 puts one enforcement point, `ToolGateway.invoke`, between every agent and every tool. The model proposes a tool call; the gateway decides.

## What shipped

- **5.1-5.3:** classify by tool name, default-deny policy rules (data in Postgres), per-agent grants. Destructive is a code hard-stop.
- **5.4:** four read tools under `src/aegis/tools/` (`fetch_signals`, `search_code`, `list_deploys`, `retrieve_knowledge`).
- **5.5:** MCP transport on `127.0.0.1:8002` into the same gateway, as untrusted `mcp_client` (retrieve-only).
- **5.6:** append-only `audit_log` with a hash chain. Allow and deny are both recorded.
- **5.7:** token-bucket rate limits per (agent, tool, incident) plus a per-agent cap.
- **5.8:** security tests: poisoned runbook and poisoned simulator log never reach a write tool (asserted with a registry spy). Tool-abuse cases: extra fields, path traversal, huge payload, wrong agent.
- **5.9:** every allowed result carries an `untrusted` envelope. The RCA prompt quotes evidence as `UNTRUSTED_DOCUMENT`; lines that start like `invoke:` / `tool:` are dropped. Nothing executes from text.
- **5.10:** timeout, output cap (redact then truncate with `[truncated]`), parameter key allowlist, adapter host allowlist, no redirects, in-process circuit breaker.
- **5.11:** `AEGIS_GUARDRAIL_DENY_ALL` kill switch (read on every call) and `policy_version` + `deny_all` on every audit row.

## What did not ship

- Any write tool or remediation execution (Phase 8).
- AWS, ECS, RDS, CDK (Phase 6). Rate-limit and breaker state are in-process; Redis is a Phase 6 note.
- A scorer for RCA quality (Phase 7).
- **RISK-003 is not closed.** Injection still happens. Actions are contained; RCA text is still reviewed by a human.

## Operator

```bash
AEGIS_SKIP_DOTENV=1 uv run alembic upgrade head      # adds audit_log + policy_version/deny_all columns
AEGIS_SKIP_DOTENV=1 uv run pytest tests/security tests/unit -q
# Break-glass: AEGIS_GUARDRAIL_DENY_ALL=true, restart worker + MCP, fix the rule, set back to false.
```

Do not put secrets in this note.
